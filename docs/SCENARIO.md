# LampLight — 시나리오 설계

버려진 신전에 갇혔다. 등불이 꺼지기 전에 공양물을 모아 제단에서 의식을 치러야 전각을 닫을 수 있다.
전각은 셋, 각 전각에는 서로 다른 것이 하나씩 깨어 있다.

---

## 1. 설계를 지배하는 제약

심사자는 **60초**를 쓴다. 그리고 문서만 보고 판단할 수도 있다.
따라서 모든 수치는 다음 한 문장에서 역산했다.

> 심사자가 이 게임을 처음 켜고 60초 안에, 공포의 정점을 최소 세 번 겪어야 한다.

부수 제약 다섯 가지도 전부 여기 종속된다.

| 제약 | 설계 반영 |
|---|---|
| 게임오버에 큰 이펙트 | 죽음이 곧 페이로드. 점프스케어 → Press Any Key 즉시 재시작 |
| 호러는 사운드가 적다 | 기본 상태는 **무음**. 소리는 사건이 있을 때만 |
| 30~60초 안에 재미 최대치 | 1전각 클리어 목표 **45초** |
| 조작·온보딩 간단히 | 키 3개. 하단 대사 두 줄로 끝 |
| 몬스터는 멍청하게 | AI는 순찰·시야·소리뿐. 난이도는 맵과 공양물 수로 올린다 |
| 몬스터는 플레이어 2~3배 | 전각이 올라갈수록 실제로 커진다 (아래 표) |

## 2. 심사 60초 타임라인

이게 이 문서의 핵심이다. 아래가 성립하지 않으면 나머지는 의미가 없다.

| 시각 | 화면 | 의도 |
|---|---|---|
| 0–3s | 타이틀 → Press Any Key | 마우스 안 씀. 아무 키나 |
| 3–8s | 서쪽 방에서 깨어남. 등불을 집는다<br>대사: *"등불이 꺼지면, 저것들이 나를 본다."* | 조작·목표 동시 전달 |
| 8–20s | 본전으로 나감. 첫 공양물 회수<br>**멀리서 소리 한 번** — 그리고 다시 무음 | 정적의 기준선을 깔고 한 번 깬다 |
| 20–25s | **복도를 가로지르는 요괴를 목격** (스크립트, 랜덤 아님) | ▲ **1차 정점** — "저게 뭐야" |
| 25–40s | 두 번째 공양물. 추격당하면 뿌리침 | 심박음 시작, 거리에 따라 빨라짐 |
| 40–50s | 제단 의식. **등불을 내려놓아야 한다** | ▲ **2차 정점** — 무방비 + 어둠 |
| 50–55s | 봉인. 요괴 비명. 화면 정리 | 성취 |
| 55–60s | 2전각 진입. 새 요괴 실루엣이 한 번 스친다 | ▲ **3차 정점** — "더 있구나" |

죽는 경로도 실패가 아니다. 30초에 잡히면 점프스케어(입을 벌리고 삼킴 → 암전)를 보고
Press Any Key로 즉시 같은 전각에서 다시 시작한다. **재진입에 로딩·메뉴를 두지 않는다.**

이 타임라인이 강제하는 설계 결정이 하나 있다.

> **1전각의 첫 목격은 스크립트여야 한다.** 순찰에 맡기면 심사자가 60초 동안 요괴를 한 번도 못 볼 수 있다.

## 3. 코어 루프

```
   깨어남 ─→ 등불 획득 ─→ 공양물 수집 ─→ 제단 의식 ─→ 봉인 ─→ 다음 전각
                              ↑              │
                              └── 요괴 회피 ──┘
                                     │
                                   잡힘 → 점프스케어 → Press Any Key → 재시작
```

- **등불** — 유일한 시계이자 유일한 시야. 원형으로 밝힌다. 꺼지면 끝
- **공양물** — 등불 반경 안에 들어오면 빛난다. 어디 있는지 알려주지 않고, 가까이 가면 알게 된다
- **제단 의식** — 채널링 동안 등불을 제단에 올려놓는다. 플레이어는 어둠 속에 선다. 이 게임에서 가장 무서운 몇 초
- **요괴** — 순찰 / 추격 / 수색. 시야와 소리로만 판단한다. 지형에 갇히지 않는 것 외의 영리함은 없다

## 4. 3전각 / 3요괴

| | 1전각 · 외전 | 2전각 · 본전 | 3전각 · 내전 |
|---|---|---|---|
| **요괴** | **역골** | **상주** | **석신** |
| 정체 | 관절이 거꾸로 꺾여 기는 몸 | 검은 상복의 키 큰 것 | 뿌리로 바닥을 끄는 돌덩이 |
| 실루엣 | 낮고 넓음, 배가 위로 | 길쭉하고 높음 | 넓고 두껍고, 팔이 여섯 |
| 재질 | 앙상한 뼈 | 매끈한 살 · 검은 천 | 금 간 돌 · 그 안의 불 |
| 크기 | 플레이어 **1.9배** | **2.7배** | **2.8배** |
| 이동 | 게걸음, 관절이 튐 | 성큼성큼 느리게 | 다리 없이 미끄러짐 |
| 무서운 지점 | 빠른데 눈귀가 어둡다 | 멀리서 보고 안 놓는다 | 발소리를 전부 듣는다 |

세 축이 전부 반대로 갈린다 — 재질, 속도, 감각. 전각마다 인상이 안 겹치고,
전각이 올라갈수록 **낮다 → 길다 → 두껍다**로 실루엣이 바뀐다.
심사 영상을 찍어도 세 장면이 서로 안 닮는다.

크기 배율은 실측값이다(§8.3 PRESENCE). 문서가 적었던 1.4 / 2.0 / 3.0배는 아트가 못 따라간다.

이름은 신전 맥락으로 맞췄다. 검은 정장의 키 큰 것은 그대로 두면 겉돌지만
**상주**(喪主, 장례를 주관하는 사람)로 읽으면 자리를 얻는다.
마지막 것은 신전이 모시던 우상 자체가 깨어난 것이라 **석신**(石身)이다.

## 5. 레벨링 수치

> 몬스터를 똑똑하게 만들지 않는다. 맵과 공양물 수와 등불 시간만 조인다.

| | 1전각 | 2전각 | 3전각 |
|---|---|---|---|
| 맵 | 34×24 | 42×30 | 52×36 |
| 공양물 (배치 / 필요) | 2 / 1 | 3 / 2 | 4 / 3 |
| 최단 경로 | 52타일 = 13초 | 79타일 = 20초 | 122타일 = 30초 |
| **목표 클리어** | **45초** | **65초** | **90초** |
| 등불 | 60초 | 70초 | 90초 |
| 의식 채널링 | 6초 | 7초 | 8초 |
| 요괴 | 1 | 1 | 1 |
| 요괴 추격 속도 | 3.4 | 3.9 | 4.6 |

목표 클리어는 최단 경로의 약 3.5배로 잡았다 — 초행에 헤매고, 피하고, 의식을 치르는 몫이다.
등불은 목표 클리어의 1.3~1.4배. **아슬아슬하되 불합리하지 않다.**

### 시계는 하나뿐이다

현재 코드에는 제한시간(`DeadlineSeconds` 120/180/240초)이 따로 있다.
측정해보니 **최단 경로의 8~9배**라 한 번도 압박이 되지 않는다.
심사자가 60초 안에 두 개의 시계를 이해할 이유도 없다.

> **`DeadlineSeconds`를 삭제하고 등불만 시계로 남긴다.**

## 6. 온보딩 — 하단 대사만 쓴다

상단에 목표를 띄우지 않는다. 쯔꾸르식 하단 대사 상자로 전부 처리한다.

| 시점 | 대사 |
|---|---|
| 시작 | `등불이 꺼지면, 저것들이 나를 본다.` |
| 시작 (2줄째) | `[WASD] 걷기   [Shift] 뛰기   [E] 줍기` |
| 첫 공양물 | `하나. 아직 모자라다.` |
| 마지막 공양물 | `제단으로.` |
| 의식 시작 | `등불을 내려놓아야 한다.` |
| 봉인 | `닫혔다.` |
| 다음 전각 | `아직 남았다.` |

전부 한 줄, 전부 반말, 전부 명사로 끝난다. 읽는 데 1초를 넘기지 않는다.
**튜토리얼 화면도, 설명서도, 조작키 팝업도 만들지 않는다.**

---

## 7. 사운드 — 기본값은 무음

호러 게임에서 소리는 계속 깔려 있는 게 아니라, 없다가 생긴다.

| 상태 | 소리 |
|---|---|
| 평상시 | **무음.** 발소리와 등불 심지 소리만 |
| 요괴가 근처 | 심박음. 거리에 따라 0.95초 → 0.30초 간격 |
| 발각 순간 | 스팅어 한 방 → 추격 루프 |
| 추격 종료 | 페이드 아웃이 아니라 **하드 컷**. 갑자기 다시 무음 |
| 의식 중 | 무음 + 심지 소리만. 요괴가 오면 심박음만 |
| 잡힘 | 비명 → **완전 무음** → 점프스케어 |

추격이 끝날 때 소리를 뚝 끊는 게 핵심이다. 정적이 다시 기준선이 되어야 다음 스팅어가 먹힌다.

---

## 8. 죽음 연출

전각마다 다른 연출을 쓴다. 공통 골격은 파피 플레이타임의 순서를 따른다.

```
  잡힘 → 히트스톱 (0.1s, 무음)
       → 요괴가 화면을 채우며 입을 벌린다 (24fps 프레임 시퀀스)
       → 입 안이 화면을 삼킨다
       → 암전
       → Press Any Key
```

정지 이미지를 확대하는 게 아니라 **프레임 시퀀스를 재생**한다.
요괴마다 입 모양과 삼키는 속도가 달라야 세 죽음이 서로 다르게 기억된다.

## 9. 맵 정리 실행안

측정 결과와 그에 따른 조치다. 근거는 전부 실측이다.

| 항목 | 측정값 | 판정 | 조치 |
|---|---|---|---|
| 맵 크기 | 3.6 / 5.6 / 8.3 화면 | 적정 | 유지 |
| 최단 경로 | 13 / 20 / 30초 | 적정 | 유지 |
| 제한시간 여유 | **8~9배** | 과다 | `DeadlineSeconds` 삭제 |
| 시작 방 | 56~64타일 **막다른 방** | 낭비 | 등불 획득 장소로 전환 |
| 경로 밖 바닥 | 8% / 13% / **14%** | 3전각 과다 | 3전각 막다른 가지 정리 |
| 방 식별성 | 전부 빈 직사각형 | **최악** | 방마다 랜드마크 세트피스 |
| 스폰 포인트 | 8개 배치 / 1개 사용 | 잔재 | 미사용 7개 제거 |
| 적 종류 | Walker·Wanderer·Runner 필드 잔존 | 잔재 | 요괴 1종으로 정리 |

### 시작 방을 살리는 법

세 맵 모두 서쪽 끝 방이 막다른 골목이다. 플레이어는 한 번 지나가고 다시 안 온다.
없애는 대신 **역할을 준다** — 여기서 깨어나고, 여기서 등불을 집는다.
지나가는 방이 아니라 도입부가 되면 56타일이 값을 한다.

### 랜드마크

지금은 방이 전부 같아 보인다. 화면에 20×11타일밖에 안 보이는 게임에서
방이 구분되지 않으면 심사자는 길을 잃고, 그건 "온보딩 간단히"의 정반대다.

보유 애셋으로 방마다 하나씩 박는다 — 세트피스 6종, 오브젝트 111종이 이미 있다.

| 방 | 랜드마크 |
|---|---|
| 시작 방 | `large_benches_pair` + `prop_candle_tall` |
| 본전 | `altar_5x5` (제단) |
| 무너진 방 | `collapse_3x3` + `large_pillar_fallen_long` |
| 납골 | `ossuary_3x3` + `prop_bones_pile` |
| 회랑 | `pillars_5x5` |
| 우물방 | `prop_basin` + `prop_grate` |

## 10. 삭제 대상

되돌리지 않는다. 호환 계층도 두지 않는다.

- `DeadlineSeconds` — 시계는 등불 하나
- `WalkerCount` / `WandererCount` / `RunnerCount` — 요괴 1종으로 통일
- `OilCanisters` / `Stones` — 60초 안에 쓸 일이 없는 소모품
- 미사용 스폰 포인트 7개 × 3맵
- 랜덤 요소 전부 (맵, 스폰 위치, 공양물 배치) — 이미 고정 완료
- 점수 — 클리어가 목적이다
