# one_lantern — 아트 에셋 패키지 v3.1

탑다운 청각 의존 스텔스 호러 `one_lantern`의 아트 에셋 일체.
기획 문서(`01`~`07`)와 별개로, **이 패키지만 있으면 맵 렌더링이 가능하도록** 구성했다.

---

## 1. 규격 — 이것만 지키면 된다

| 항목 | 값 |
|---|---|
| **논리 단위** | **1타일 = 원본 32 px = 화면 64 px** |
| **확대** | **×2 NEAREST 고정.** 보간(bilinear 등) 사용 금지 — 픽셀이 뭉개진다 |
| 배경 | RGBA 투명 |
| 좌표 기준 | 오브젝트는 **타일 중심점** 기준. 좌상단 = `(px_x − w/2, px_y − h/2)` |

```
타일 → 픽셀(중심) :  px_x = col * 64 + 32,  px_y = row * 64 + 32
픽셀 → 타일       :  col = floor(px_x / 64),  row = floor(px_y / 64)
```

**모든 크기 정보는 `objects_manifest.json`에서 읽는다. 하드코딩하지 말 것.**

## 3. 네이밍 규칙

```
obj_<category>_<name>[_variant].png
```

| 예 | 뜻 |
|---|---|
| `obj_walldeco_hole.png` | 벽 장식 · 무너진 구멍 |
| `obj_walldeco_hole_mirror.png` | 위의 **좌우 반전본** |
| `obj_container_drawer_open.png` | 컨테이너 · 서랍 · 열림 상태 |
| `obj_artifact_bell_buried.png` | 유물 · 종 · 반매몰형 |

**`_mirror` 접미사는 좌우 반전본**이다. 같은 벽면에 원본과 반전본을 섞어 쓰면 반복감이 사라진다.
**`_open` / `_closed`, `_locked` / `_open`** 은 같은 좌표에서 교체되는 상태 쌍이다.

## 4. footprint

`objects_manifest.json`의 `footprint` 값이 오브젝트가 차지하는 타일 수다.

| 값 | 원본 px | 의미 |
|---|---|---|
| `1x1` | 32×32 | 1타일 |
| `2x2` | 64×64 | 2×2타일 |
| `3x3` | 96×96 | 3×3타일 |
| **`3x1`** | 96×96 | **벽면 위에 겹쳐 그린다. 통행 판정 없음** (문 개구부는 예외) |

## 5. 타일셋

| 항목 | 값 | 주의 |
|---|---|---|
| 폭 | **512 px 고정** | |
| `columns` | **8 고정** | **바꾸면 배치된 모든 타일의 gid가 밀려 맵 전체가 깨진다** |
| 확장 | **세로로만** | 새 타일은 시트 끝에 이어 붙인다 |
| 정의 | TMX에 **인라인** | 외부 `.tsx` 참조 금지 |
| 배치 | TMX와 PNG는 **같은 폴더** | 분리하면 전 타일이 빨간 X가 된다 |

### 타일 ID (gid = tileid + 1)

| tileid | 내용 |
|---|---|
| 0 | 바닥 A (기본) |
| 1 | 벽 솔리드 (오토타일 폴백) |
| 2 | 바닥 B (변형) |
| 3 | 바닥 C — `noisy = true` **밟으면 소리** |
| 4, 5 | 바닥 D(이끼) · E(젖음) |
| **8 ~ 23** | **벽 엣지 16종** — `tileid = 8 + mask` |

**벽 오토타일 마스크 비트: `1=N, 2=E, 4=S, 8=W` · 맵 바깥은 벽으로 취급한다.**

### 충돌 판정

```
walls[row][col] != 0   → 통과 불가
walls[row][col] == 0   → 통과 가능
맵 범위 밖             → 통과 불가
```

타일 프로퍼티 `walkable`(bool), `noisy`(bool)도 함께 제공한다. **좌표 하드코딩 대신 프로퍼티를 읽을 것.**

## 6. 절대 어기면 안 되는 것

| # | 규칙 | 어기면 |
|---|---|---|
| 1 | **에셋에 자체 발광(glow)을 넣지 않는다** | 어둠 속에서 위치가 노출되어 소리 기반 코어가 붕괴한다 |
| 2 | 타일셋 `columns=8`, 폭 512px 유지 | 맵 전체의 gid가 밀린다 |
| 3 | TMX와 `temple_tileset.png`를 같은 폴더에 둔다 | 전 타일 빨간 X |
| 4 | 확대는 **×2 NEAREST** | 픽셀아트가 뭉개진다 |
| 5 | 크기·경로를 코드에 하드코딩하지 않는다 | 에셋 갱신 시 전부 깨진다 |

## 7. 검수 필요 항목 (v3.1 기준 미해결)

**아래 항목은 알려진 문제다. 그대로 쓰지 말고 담당자에게 확인할 것.**

### 7-1. 알파 결함 — 재생성 대기

| 에셋 | 문제 | 영향 |
|---|---|---|
| `walldeco_arch` / `_mirror` | **불투명 면적 63%.** 좌우가 비어 있고 아치 내부 3,417px이 **투명** | 벽면에 배치하면 주변 벽돌이 끊기고, 개구부로 바닥이 비친다 |
| `exit_locked` | **불투명 면적 15%**, 32×32 | 거의 선화 상태. 벽에 얹으면 아무것도 안 보인다 |
| `exit_open` | **불투명 면적 28%**, 32×32 | 균열 내부가 투명이라 "뚫린 벽"으로 읽히지 않는다 |

**`exit` 2종은 규격 자체가 어긋나 있다.** 기획상 탈출구는 **96×96(3타일)** 이어야 하는데 현재 32×32다.

### 7-2. 개구부가 투명 — 정책 결정 필요

`walldeco_arcade`(1,705px) · `walldeco_hole`(1,124px) · `door_open`(2,231px)의 개구부 안쪽이 **투명**이다.

- **벽 위에 얹는 경우** — 뒤의 벽돌이 비쳐서 "뚫린 것"으로 안 보인다 → **불투명 검정으로 채워야 한다**
- **판자 사이 틈** (`door_open`, `door_broken`) — 벽이 비치는 게 자연스러우므로 **그대로 두는 것이 맞다**

둘을 구분해서 처리할 것.

### 7-3. 세계관 규칙 위반 — 사용 보류

| 에셋 | 문제 |
|---|---|
| `large_statue_kneeling` | **얼굴이 노출된 조각상.** 기획 금지 사항(*신상·조각상을 만들지 않는다*) 위반 |
| `large_carpet_round_seal` | **펜타그램.** 기획 금지 사항(*해독 가능한 문자 체계를 만들지 않는다*) 저촉 |
| `artifact_*` 8종 | **금색.** 기획상 유물은 *무채색이고 빛을 반사하지 않고 삼킨다.* 어둠 속에서 유물이 눈에 띄면 소리 기반 탐색이 성립하지 않는다 |

`artifact` 8종이 가장 시급하다. **게임 코어에 직접 영향을 준다.**

### 7-4. 카펫 사용 규칙

`large_carpet`(회백색)이 아니라 **`large_carpet_runner`(붉은색)만 사용**한다. 회백색은 돌바닥과 구분되지 않는다.
세로로 놓을 때는 90° 회전. **한 방에 세로 XOR 가로, 혼합 금지.**
